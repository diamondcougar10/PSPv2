================================================================================
                  HOW_TO_ADD_GAMES.txt - PSPV2 Game Installation
================================================================================

Welcome to PSPV2! This guide explains how to add your PSP games on both the
Windows (PC) version and the Android version of PSPV2.

Supported game file types: .ISO  .CSO  .PBP  .CHD  .PRX  .ELF
(The PC version primarily uses .ISO and .CSO.)


################################################################################
#  PART A - ANDROID (Phones, Tablets, Handheld Consoles)
################################################################################

On Android, PSPV2 does NOT copy games into its own folder. Modern Android
sandboxes apps, so instead you simply point PSPV2 at the folder where your
games already live, and it scans them in place. Games are launched through the
installed PPSSPP app.

--------------------------------------------------------------------------------
STEP 1: INSTALL PPSSPP (one time)
--------------------------------------------------------------------------------
1. Open the Google Play Store.
2. Install "PPSSPP - PSP emulator" (free) or "PPSSPP Gold".
   PSPV2 hands each game to PPSSPP to actually run it.

--------------------------------------------------------------------------------
STEP 2: PUT YOUR GAMES SOMEWHERE ON THE DEVICE
--------------------------------------------------------------------------------
1. Copy your .ISO / .CSO / .PBP files onto the device or an SD card using a
   file manager, a USB cable, or a download.
2. A common, easy location is:
      Internal Storage > Download
   or a dedicated folder you make, e.g.:
      Internal Storage > PSP > GAMES

   You can keep games in subfolders - PSPV2 scans subfolders too.

--------------------------------------------------------------------------------
STEP 3: POINT PSPV2 AT THAT FOLDER
--------------------------------------------------------------------------------
1. Open PSPV2.
2. Go to the "Settings" category and select "Scan ROM Folder".
3. The Android folder picker opens. Browse to the folder that holds your games
   (for example Download, or PSP/GAMES) and tap "USE THIS FOLDER" / "Allow".
4. PSPV2 scans the folder, and every game appears under the "Games" category.

That folder choice is remembered. Each time you open PSPV2 it re-scans the same
folder automatically, so newly added games show up without re-picking it.

--------------------------------------------------------------------------------
STEP 4: PLAY!
--------------------------------------------------------------------------------
1. Scroll to the "Games" category.
2. Select a game and press the Confirm button (A / Cross on a controller).
3. The PSP boot animation plays, then the game opens in PPSSPP.

--------------------------------------------------------------------------------
ANDROID TROUBLESHOOTING
--------------------------------------------------------------------------------
- "Nothing happens when I launch a game": make sure PPSSPP is installed.
- "No games found": confirm the files end in .iso, .cso, .pbp, .chd, .prx or
  .elf, and that you picked the folder that actually contains them (or a parent
  folder of them).
- "Games disappeared after I moved them": Android access is tied to the folder
  you granted. If you move games to a new folder, run "Scan ROM Folder" again
  and pick the new location.
- Zipped games (.zip / .7z) must be extracted first on Android - PSPV2 only
  lists actual game files, it does not auto-extract on Android.


################################################################################
#  PART B - WINDOWS (PC)
################################################################################

On the PC version, PSPV2 keeps your games in its own "Games" folder and can
auto-extract downloads.

--------------------------------------------------------------------------------
STEP 1: GET YOUR GAME FILES
--------------------------------------------------------------------------------
You need valid PSP game files to play (.ISO or .CSO).

We have made this easy for you!
1. In the PSPV2 app, scroll to the "PlayStation Store" icon (Network icon).
2. Select "ROM Store". This will open a safe website to download games.
3. Download the game files (usually .zip or .7z) to the "Downloads" folder inside the app.
   (You can open this folder easily by selecting "Downloads Folder" in the app).

Note: The app will automatically extract and install games found in the "Downloads" folder!

--------------------------------------------------------------------------------
STEP 2: LOCATE THE GAMES FOLDER
--------------------------------------------------------------------------------
1. Open the folder where you installed PSPV2.
   (Default is usually C:\Program Files (x86)\PSPV2)
   
2. Look for a folder named "Games".

--------------------------------------------------------------------------------
STEP 3: COPY YOUR GAMES
--------------------------------------------------------------------------------
1. Drag and drop your .ISO or .CSO files directly into the "Games" folder.

   Example:
   PSPV2\Games\GodOfWar.iso
   PSPV2\Games\Tekken.cso

--------------------------------------------------------------------------------
STEP 4: PLAY!
--------------------------------------------------------------------------------
1. Run PSPV2.exe.
2. Scroll to the "Game" icon (the controller icon).
3. Scroll down - your new games will appear in the list automatically.
4. Press "X" (or Enter) to play!

--------------------------------------------------------------------------------
WINDOWS TROUBLESHOOTING
--------------------------------------------------------------------------------
- If your game doesn't show up, make sure it is a valid .ISO or .CSO file.
- Ensure the file is inside the "Games" folder, not a subfolder inside it.
- You can also place games in the "Downloads" folder, and the app will 
  automatically find them and move them to the Games folder for you.
